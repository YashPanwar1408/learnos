# LEARNOS Competition Demo Script

Use `/learner-twin`, enable Demo mode, and press `Reset Demo` before every run.

## 0:00 Hook

“Most learning software measures what a student opened. LEARNOS measures what changed in the student.”

Show the Learner Twin. Point to `Mastery 41%` and `Confidence 95%`.

## 0:20 Problem

“This student is studying Computer Networks. They can recognize the subnetting formula, but their confidence is much higher than their reasoning quality.”

Select the Network vs host bits concept and show the misconception panel.

## 0:35 Student attempt

In “Prove that you learned it”, leave the initial answer as `64`, confidence at `95`, and submit the explanation.

## 0:55 Diagnosis

“LEARNOS does not call this a bad score and move on. It records the evidence: the learner is confusing network bits with host bits.”

Show the confidence gap and “Possible illusion of understanding”.

## 1:15 Intervention

Open `/missions`. Show the timeline and the reason: “You repeatedly confuse network bits with host bits.”

Open `/tutor`, select Socratic mode, and say: “Before we calculate, which bits identify the network?”

## 1:35 Verification

Return to the Twin. Change the answer to `62`, explain that a `/26` leaves 6 host bits and therefore 62 usable hosts, and submit with confidence around `78`.

“Correctness is one signal. The explanation is the verification.”

## 1:55 Learner Twin

Show the concept map, reasoning quality, confidence calibration, and review schedule. Explain that the next review is earlier because confidence was previously high while reasoning was incomplete.

## 2:15 Teacher insight

Open `/teacher`. Show the aggregate class heatmap and the recommended ten-minute visual subnetting activity.

“The teacher sees the shared misconception, not private student transcripts.”

## 2:35 Closing

“LEARNOS continuously diagnoses, decides, teaches, practices, verifies, and remembers. It is an AI Learning Operating System, not a chatbot with a quiz button.”
